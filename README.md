# Miguel López Contreras · Currículum online

Web estática que amplía mi currículum: formación, prácticas, proyectos y habilidades.

**Ver la web:** https://kiravsl2018.github.io/MiguelLopez/

## Páginas

| Página | Contenido |
|---|---|
| `index.html` | Presentación, datos clave y contacto |
| `formacion.html` | CFGS en DAW (en curso), CFGM en SMR y formación complementaria |
| `experiencia.html` | Prácticas como técnico de IT en el Hotel Finca Cortesín |
| `proyectos.html` | Homelab: servidor casero con Ubuntu Server y Docker |
| `habilidades.html` | Habilidades técnicas, idiomas y competencias personales |

## Estructura

```text
MiguelLopez/

├── proyectos.html
```

Hecho con HTML, CSS y JavaScript, sin frameworks. Se publica con GitHub Pages desde la rama `main`.
